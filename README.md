# 🧬 Mapa Cromosómico de Yuca (Manihot esculenta)

Mapa cromosómico interactivo con datos simulados de 18 cromosomas de yuca, 
mostrando QTLs asociados a características agronómicas y marcadores SSR.

## 📊 Contenido

- **18 cromosomas** (Me_01 a Me_18) con longitudes en Mb
- **16 QTLs** para 8 características: rendimiento, tolerancia a sequía, 
  contenido de almidón, cianuro, floración, resistencia a CMS, 
  resistencia a tizón, y altura de planta
- **20 marcadores SSR** distribuidos en los cromosomas

## 🚀 Uso

```bash
python mapa_cromosomico.py
```

## 📦 Dependencias

- numpy
